      Using the Field Logger

      Works offline. Once installed (open it once with internet, then use the browser's Add to Home screen or Install app), it needs no connection on site. Everything stays on this device. Check the top of the screen says Ready offline ✓ before you go; if it doesn't, open the app once more with a connection.

      Start at the same moment you start the sound level meter. Log moment stamps the time the instant you tap it; type a description before or after. Start range / End range marks something that lasts. Pause marks the paused time as excluded.

      Exclude anything that should not count in the assessment, such as you talking or wind on the microphone. It is still kept and shown, just left out of the assessed figures.

      Site and job details (job, client, location, operator, meter, calibration, weather, noise environment) fill the Environmental Noise Measurement sheet on the laptop. Fill them in before Start or any time after; the job, client, operator, meter and calibrator are remembered for the next position.

      Planned length: enter the minutes before Start and the screen counts down. When the time is up the tablet vibrates and the screen flashes, with no sound so the meter isn't affected. Stop the meter, then Stop session.

      Photos: add them to any observation (tap it, then Add photo) or of the measurement position (Site details). They are shrunk to save space and travel with the exported session.

      Listen back with ▶ on any entry: it plays the few seconds before a moment (you log a sound after hearing it) or the start of a range. While logging, use headphones: through the speaker the playback would be picked up by the meter. When you stop, the session opens for review so you can listen and fill in notes before exporting; Review in Saved sessions opens it again later.

      Keep this screen open while logging. The screen is kept awake, but switching to another app can stop the audio recording on some tablets.

      Afterwards, tap Export on the session and move the .zip file to the laptop (USB, email, cloud drive). In the Acoustic Monitoring Software use Import and choose the .zip; the session and its audio appear ready to bind to the meter's file, exactly like a session logged on the laptop.

      If export or the microphone fails with a message such as Permission denied, try again first: the browser sometimes refuses the first attempt. If it keeps failing, check this site's permissions in Chrome (⋮, Settings, Site settings): the microphone must be allowed, and downloads must not be blocked. Nothing is lost by retrying; sessions stay saved on the device until you delete them.
