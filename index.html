    Using the Field Logger

    Works offline. Once installed (open it once with internet, then use the browser's Add to Home screen or Install app), it needs no connection on site. Everything stays on this device.

    Start at the same moment you start the sound level meter. Log moment stamps the time the instant you tap it; type a description before or after. Start range / End range marks something that lasts. Pause marks the paused time as excluded.

    Exclude anything that should not count in the assessment, such as you talking or wind on the microphone. It is still kept and shown, just left out of the assessed figures.

    Keep this screen open while logging. The screen is kept awake, but switching to another app can stop the audio recording on some tablets.

    Afterwards, tap Export on the session and move the .zip file to the laptop (USB, email, cloud drive). In the Acoustic Monitoring Software use Import and choose the .zip; the session and its audio appear ready to bind to the meter's file, exactly like a session logged on the laptop.
